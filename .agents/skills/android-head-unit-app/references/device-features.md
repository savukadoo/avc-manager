# Vehicle and device features

## OBD dashboard and adapters

- Keep the vehicle profile, Bluetooth transport and dashboard configuration independently selectable. Start with supported standard readings. Gate manufacturer-specific readings by engine variant, transmission, ECU and protocol where those affect the decoder. A shared engine across model years is a research lead. An ECU response establishes communication. Compare the decoded units and values with a reference scanner before describing a custom reading as verified.
- Let one connection owner serialize requests to the adapter. Measure completed queries per second, response delays and timeouts before raising a refresh rate. Give visible readings priority. A failed optional reading should not take down a healthy dashboard. Distinguish an unsupported channel, a timeout, a valid zero and a retained sample after disconnect. Show the shared connection state once, with the age beside each retained value.
- Store stable metric identifiers. For a group such as DPF, let the chosen primary metric occupy one card. A tap can open history and related metrics. Mark gaps in history and calculate averages from actual samples. For AVC Manager the window is ten one-minute buckets. A profile change must also change the readings, support map and history attributed to the vehicle.
- For monitoring features, exercise the read path with synthetic replies for decoding, units, fault categories and reconnects. Simulate the adapter staying connected after ignition off while the ECU stops answering. A genuine zero, an unanswered query and the first fresh reply after wake-up should produce three distinguishable outcomes. Verify the real adapter and ignition cycle in the parked vehicle.
- Check Bluetooth permissions against both the installed OS and the app's target SDK. On Android 12+ with a target of API 31+, discovery uses the runtime `BLUETOOTH_SCAN` permission and paired-device communication uses `BLUETOOTH_CONNECT`. Test grant, denial and revocation with a saved adapter, including an in-place update. Keep the chosen adapter and the auto-connect preference when access is unavailable. [Android Bluetooth permissions](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions)

## Sound, media and files

- A live slider should update while dragged. Coalesce writes at the vendor service boundary if needed, and reconcile the displayed value against readback. Exercise unavailable, pending and confirmed states. A moving fader alone cannot establish front/rear routing. In the parked car, use a known audible track and check the intended speakers.
- Keep the current player and queue independent of the visible tab. Verify track change, audio focus, return from full-screen video and an empty or filtered library. Reveal the selected track when it changes without resetting a user's browsing position on every progress tick. A supported file extension still needs a decoder and a working output route.
- Distinguish app-owned files from items found through MediaStore, USB or the document picker. Test removable storage through the head unit's actual mount and permission flow. For local laptop uploads, check pairing, transport security, storage headroom and interruption before a partial file becomes playable. An in-place update should preserve the library.

## Connectivity, weather and maps

- Firewall enforcement and packet capture have separate state and outcomes. Show which is active. For a destination marker, show the endpoint and the scope of the proposed rule together. Label inferred IP geography. Make any external DNS, registration or location lookup visible at the point where information leaves the device.
- Show cached weather on startup, distinguish its age from network availability, and retry when connectivity returns. Track the last successful forecast separately from the last request. Give GPS a manual-place fallback. Distinguish a radar observation's timestamp from a forecast model's valid time.
- Keep remote maintenance scoped to the user's authorised connection. A Wi-Fi debugging session belongs to the selected trusted network and its expiry. Treat cellular connectivity, an active local transfer and an authenticated maintenance connection as distinct capabilities. For physical checks use the address currently shown on the unit and preserve its settings.
